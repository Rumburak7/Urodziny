# Życzenia urodzinowe

Otwórz stronę bez niczego w adresie - pojawi się generator: wpisz imię, ewentualnie wiek,
język (polski / niemiecki) i własne życzenia, potem „Kopiuj link” albo „WhatsApp”.

Osoba, która dostanie link, widzi życzenia z imieniem, tort ze świeczkami (dotknąć = zdmuchnąć),
konfetti, balony i melodię „Happy Birthday”.
