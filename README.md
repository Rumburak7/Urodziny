# Życzenia linkiem

Otwórz stronę bez niczego w adresie - pojawi się generator: wybierz okazję
(Urodziny, Wielkanoc, Boże Narodzenie, Nowy Rok), wpisz imię, język (polski / niemiecki)
i ewentualnie własne życzenia, potem „Kopiuj link” albo „WhatsApp”.

Każda okazja ma swoją scenę: tort ze świeczkami, pisankę z kurczaczkiem,
choinkę z lampkami i śniegiem albo fajerwerki - i swoją melodię.
